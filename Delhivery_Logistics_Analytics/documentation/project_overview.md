# Project Overview

## Business context
Recorded logistics journey times can differ from estimated journey times.
Managers need a way to identify where additional investigation may be useful.

## Business question
Which parts of the delivery network should management prioritize for
operational investigation, and why?

## Objectives
1. Profile and clean journey data.
2. Build a subjourney-level analytical dataset.
3. Compare actual journey times with OSRM estimates.
4. Compare route types and source-to-destination corridors.
5. Communicate findings through a Tableau dashboard.

## Intended audience
Operations managers, logistics analysts, and business analysts.

## Deliverables
- SQL scripts
- Prepared CSV dataset
- Tableau dashboard
- Project documentation

## Scope
This is a historical-data portfolio case study. Findings are descriptive
and do not establish the causes of observed time gaps.
