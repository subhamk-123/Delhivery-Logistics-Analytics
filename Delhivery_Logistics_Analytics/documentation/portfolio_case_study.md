# Portfolio Case Study: Delhivery Logistics Analytics

## Challenge
How can historical logistics records help managers prioritize where
to investigate differences between recorded journey times and estimates?

## Approach
I used MySQL to profile and clean journey data, create subjourney-level
time-gap and efficiency metrics, and aggregate results by route type
and corridor. I then connected the prepared dataset to Tableau and
built a dashboard to compare volumes and time-related performance measures.

## Tools
MySQL, SQL, Tableau, CSV data preparation.

## Selected results
- 14,817 distinct trips in the clean analysis.
- 26,368 subjourney rows in the selected analytical representation.
- FTL average time gap: approximately 157.81 minutes.
- Carting average time gap: approximately 55.89 minutes.
- Carting had a higher relative ratio than FTL, illustrating why more
  than one metric is needed.

## Business value
The dashboard helps prioritize corridors for validation and investigation.
It supports evidence-led questions rather than unsupported conclusions
about causes or financial impact.
